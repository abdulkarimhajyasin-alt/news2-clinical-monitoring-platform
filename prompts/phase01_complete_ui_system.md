# PHASE 01 — COMPLETE UI/UX SYSTEM IMPLEMENTATION

## Objective

Build the complete frontend UI system for the NEWS2 Hemodialysis Monitoring Platform.

This is a clinical research platform focused on early detection of clinical deterioration in hemodialysis patients using NEWS2.

The implementation must be production-quality, visually attractive, medically appropriate, Arabic-first, and consistent across all screens.

---

# CRITICAL RULES

## DO NOT CHANGE

- Existing architecture
- Existing database structure
- Existing NEWS2 workflow
- Existing research workflow
- Existing navigation hierarchy

Use the architecture document as the source of truth.

---

# VISUAL IDENTITY

Use the provided Stitch screens ONLY as visual inspiration.

Preserve:

- Overall layout
- Sidebar style
- Card style
- Medical dashboard feeling
- Color palette
- Information density
- Typography style
- Spacing system

Do NOT copy screens literally.

Improve them professionally.

---

# ANIMATION SYSTEM

Implement subtle, professional medical animations.

- Heartbeat pulse for critical alerts
- Soft monitoring shimmer
- Animated KPI counters
- Smooth chart transitions
- Medical loading states
- Alert fade/slide animations
- Risk color transitions

No flashy effects.

Full RTL support.
Future English support must remain possible.
