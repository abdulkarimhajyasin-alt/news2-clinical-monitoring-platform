# Project Scope

This project is a PhD Research MVP for the NEWS2 Hemodialysis Monitoring Platform. It supports structured observation of hemodialysis patients, clinical deterioration logging, response documentation, response time tracking, and research dataset preparation.

The platform provides clinical decision support only. It does not replace physician judgment, nursing assessment, local escalation policy, or emergency care protocols.

The UI is Arabic-first with RTL behavior. Code, APIs, database tables, and fields use English identifiers to support maintainability, integration, and future internationalization.

The long-term path may evolve into a healthcare SaaS platform, but the MVP is scoped to a controlled research setting.

Excluded from the MVP:

- APK/mobile app packaging
- WhatsApp integration
- SMS integration
- Device integration
- AI/ML prediction
- Hospital information system integration
- Multi-center SaaS operations
